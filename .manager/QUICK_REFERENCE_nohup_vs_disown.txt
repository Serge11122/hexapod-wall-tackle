QUICK REFERENCE: nohup vs disown for Background Process Launches
================================================================================

DECISION: SWITCH FROM nohup TO disown

OLD PATTERN (REMOVE):
  nohup .venv/bin/python -u script.py > script.log 2>&1 & pid=$!

NEW PATTERN (ADOPT):
  .venv/bin/python -u script.py > script.log 2>&1 & pid=$!
  disown

RISK: SIGHUP Handling
================================================================================

Context:           Risk Description
────────────────────────────────────────────────────────────────────────
Interactive shell  Process terminates if terminal closes unexpectedly
Cron job           NO RISK — no terminal, no SIGHUP sent ✓
tmux session       NO RISK — tmux manages signals, not shell ✓
Supervisor daemon  NO RISK — background daemon, no SIGHUP sent ✓

RLQuest deployment: ALL non-interactive contexts → NO RISK

Mitigation (if needed): Add to Python script before any other code:
  import signal
  signal.signal(signal.SIGHUP, signal.SIG_IGN)  # Optional defense

================================================================================
CRITICAL DIFFERENCE: PID Tracking
================================================================================

Problem (nohup):
  $ nohup python train.py > run.log 2>&1 & pid=$!
  $ echo $pid
  12345  ← This is nohup wrapper PID, NOT python PID
  $ ps -p 12345
  PID=12345 COMMAND=nohup  ← Wrong process!

Solution (disown):
  $ python train.py > run.log 2>&1 & pid=$!
  $ disown
  $ echo $pid
  12346  ← This IS python PID
  $ ps -p 12346
  PID=12346 COMMAND=python  ← Correct process!

Impact: Supervisor can track process reliably without pgrep/ps lookup.

TESTING CHECKLIST
================================================================================

Before deploying disown pattern, manually test:

1. Start: cmd > log.txt 2>&1 & pid=$!; disown
2. Verify PID: ps -p $pid (should show python, not nohup)
3. Check log: tail -f log.txt (should show live output)
4. Kill by PID: kill $pid (should terminate immediately)
5. In tmux: close window, verify process still runs: ps aux | grep cmd
6. Final log: Verify no truncation, all output captured
